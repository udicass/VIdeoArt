# Site Vision: Synthetic Desire

**Stitch Project ID:** 6343532215243866841

## 1. Vision
A cinematic playground where hand gestures bridge the gap between human desire and digital simulation. Users manipulate physics-bending 3D movie layers and interact with E.V.A., an AI presence that lives between the pixels. The site aims to be a benchmark for "Human-AI-3D" multi-modal interaction.

## 2. Core Mechanics
*   **Gestural Physics**: Warp video surfaces using hand distance and shapes.
*   **E.V.A. (Electronic Voice Assistant)**: A cinematic AI character that responds to voice and gestures in character.
*   **Anti-Gravity**: A toggleable world state that changes the underlying 3D physics of the scene.

## 3. Technology Stack
*   **Frontend**: Vanilla JS (ES6+), Three.js (3D Engine).
*   **AI**: Gemini API (Cloud) + Local Persona Fallback (Brain).
*   **Tracking**: MediaPipe Hand Landmarker.
*   **Styling**: Premium Vanilla CSS3 (Glassmorphism, Backdrop Blurs).
