DICT LEVELS — HOW DEEP THE MEMORY IS
L1 Built-in knowledge. Hand-crafted responses written into this movie's brain at creation. Always available, even on first load.
L2 Learned from Cloud. A response Gemini generated in a past session that was saved to memory. The AI is drawing on something it was taught.
L3 Promoted memory. A cloud-learned response that has been reused and scored highly — it has become part of the AI's permanent character for this film.
