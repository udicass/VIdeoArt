A cinematic gallery page for "Synthetic Desires" movie presets. This page allows users to browse and select different films to experience in the Cinema mode.

**DESIGN SYSTEM (REQUIRED):**
When generating this gallery, ensure it adheres to the following:
- **Backgrounds**: Use `#05050a` for the main canvas and `rgba(15, 15, 30, 0.75)` for cards.
- **Accents**: Primary `Purple (#7c5cff)`, Secondary `Emerald (#00e5a0)`, Cinematic `Rose (#ff6b9d)`.
- **Blur**: Apply `backdrop-filter: blur(20px)` for high-immersion overlays.
- **Geometry**: Use `radius-xl (28px)` for movie poster cards to give them a premium feel.
- **Typography**: Use `Outfit` for movie titles and `JetBrains Mono` for metadata (resolution, duration).
- **Vibe**: Poetic, cinematic, haunting, and high-tech.

**Page Structure:**
1. **Hero Section**: A large, atmospheric featured movie with a "Watch Now" button.
2. **Movie Grid**: A responsive grid of cinematic posters. Each poster should show:
    - Cinematic title
    - AI Persona hint (e.g., "The Ghost", "The Memory")
    - Hover effect: Glowing purple border and subtle zoom.
3. **Filter Bar**: Minimalist filters for "Aesthetic" (Glitch, Neon, Monochrome).
4. **Footer**: Navigation back to Telemetry and Cinema modes.
