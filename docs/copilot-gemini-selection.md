# How to Select Gemini Model in GitHub Copilot

1. On GitHub’s main dashboard, click the 'Open Menu' button in the top-left corner.
2. Select 'Copilot' from the menu.
3. In the Copilot chat box, click the 'Model Selector' menu.
4. Choose the Gemini model you want to use.

These steps allow you to switch to the Gemini model for Copilot chat interactions.
